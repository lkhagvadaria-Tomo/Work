# Хүсэлтийн портал — прототип

Дотоод хүсэлтийн порталын дарж туршиж болох прототип (`index.html`, нэг файл, backend шаардлагагүй).

Лавлагаа болгож legal.netcapital.mn-ийн харагдац, бүтцийг ашигласан; агуулга, зорилгыг эцсийн хувилбарт тохируулан өөрчилнө.

## Одоогийн боломжууд

- Нэвтрэх дэлгэц (Google нэвтрэлтийн загвар — production дээр жинхэнэ OAuth холбогдоно)
- Хүсэгч газар автоматаар танигдах + гараар өөрчлөх
- Ангилалын хайлттай сонголт (L01–L14)
- Тайлбар бичих алхам — туслах загвар товчнууд, тэмдэгт тоолуур
- Баримтын линк — Drive/Docs линкийн шалгалт, «Баримт хяналт» төрөлд заавал
- Яаралтай байдал / нууцлалын сонголт
- Амьд шинэчлэгддэг «Хүсэлтийн товч» самбар (гүйцэтгэлийн %, шаардлагын шалгалт, хариу өгөх хугацаа)
- «Миний хүсэлтүүд» жагсаалт (прототип горимд хөтөч дээр хадгална)
- 4 алхамт танилцуулга (tour), гэрэлтэй/харанхуй горим

## Турших

`index.html`-ийг хөтчөөр нээхэд л хангалттай.

## Нэвтрүүлэлт

Зөвхөн эзэмшигчийн зөвшөөрлөөр — нэвтрүүлэхийн өмнө user case шалгалтыг бүрэн давсан байх ёстой.

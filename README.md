# Эх үүсвэрийн дэмжлэгийн портал — прототип v1.9

Нэткапитал Санхүүгийн Группийн салбаруудын **эх үүсвэрийн хүсэлт, санал/гомдол, cashflow
төлөвлөлтийн** дотоод портал. Бүхэлдээ нэг файл — `index.html` (vanilla JS/HTML/CSS).

Амьд прототип: https://claude.ai/code/artifact/1adadf7d-6bfe-4822-926a-a1ed7037385a

## Гол боломжууд

- **Хоёр урсгал:** Хүсэлт (ЭҮ-ОООО-XXXX, 14 ангилал F01–F14) ба Санал/гомдол (СГ-ОООО-XXXX,
  G01–G06) — дараалсан дугаар, и-мэйл баталгаажуулалтын урьдчилсан харагдац, Drive-ын
  Naming Standard v1.0 архивын зам.
- **Хүүгийн засаглал:** NC-01/54-2025 тушаалын суурь хүү автоматаар; Хавсралт №2-ын матрицаар
  зөвшөөрлийн түвшинг (Х.Нургүл CIO → Б.Хуншагай CEO → SU/ТУЗ) шууд дүгнэнэ; В-8 SLA;
  зөвшөөрлийн G-Doc-оос хүү, урамшуулал, зөвшөөрөгчдийг уншиж бөглөнө (Drive connector).
- **Ухаалаг хуваарилалт:** ангиллын чиглүүлэлт + багцаас хамгийн бага ачаалалтай нь +
  өндөр дүн/удирдлагын түвшний эскалаци; мэйл болон Google Chat alert; тодруулгын урсгал;
  шийдвэрлэхэд хариу+нэмэлт мэдээллийг илгээгч рүү мэйлээр өгдөг шат.
- **Cashflow:** дараа сард дуусах данс бүрд сунгах/гарах шийдвэр, календарь, салбар бүрийн
  заавал сануулга; Excel рүү хуулах, .xlsx файлаас буулгах (SheetJS).
- **Процессын заавар:** сунгах (4 төрөл, зөвшөөрөл шалгагч тооцоолуур), бага дүнгээр сунгах,
  хаах, данс нээлтийн 12 шат (PROC-IPPDD-FUND-001, 6.0 Gate a–g).
- **49 бодит салбар** (Netcor кодтой), шинэ ажилтны угтах танилцуулга, нэгдсэн хайлт,
  AI урьдчилсан шалгалт (дүрэмд суурилсан, EOM §2.5a human-accountable), гэрэл/харанхуй горим.

## Тест

```bash
npm i          # playwright-core
npm test       # tests/regression.js — 140+ шалгалт, errors:[] байх ёстой
```

Chromium-ийн замыг `CHROME_PATH`-аар, node_modules-ийг `PW_NODE_MODULES`-ээр давхарлан зааж болно.
Дэлгэцийн зургууд `tests/out/`-д үүснэ.

## Ажлын горим

Хөгжүүлэлтийн стандарт, домэйн баримт — `CLAUDE.md`. Өөрчлөлтийн түүх, сайжруулалтын
эрэмбэлсэн сан — `BACKLOG.md`. Прототип бүх дуурайлгасан зүйлээ «прототип» гэж шошголдог;
production руу гаргахыг зөвхөн ХОБПХГ-ын шийдвэрээр хийнэ.

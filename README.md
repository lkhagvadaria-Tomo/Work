# Эх үүсвэрийн дэмжлэгийн портал — прототип

Нэткапитал Санхүүгийн Корпораци (ББСБ)-ийн салбар нэгжээс ирэх **эх үүсвэрийн бүтээгдэхүүний хүсэлтийг** ангилж, бүртгэж, аудитад бэлэн хадгалах порталын прототип (`index.html`, нэг файл).

## Зорилго

Салбар нэгжээс ирсэн эх үүсвэрийн хүсэлтийг нэг цэгээс хүлээн авч:
- дараалсан дугаартай (ЭҮ-2026-XXXX) бүртгэлд оруулах,
- эх үүсвэрийн албаны и-мэйл рүү автоматаар баталгаажуулах,
- хавсралтыг Google Drive-д он / сар / ангилал / дугаарын бүтэцтэй хадгалах,
- аудит орсон ч алдаагүй, найдвартай мөрдөгдөх бүртгэлийн сан хөтлөх.

## Прототипийн боломжууд

- Байгууллагын Google нэвтрэлтийн загвар, салбар автоматаар танигдах
- Ангилал тус бүрд нөхцөлт талбарууд (бүтээгдэхүүн, дүн, одоогийн/хүсэж буй хүү 0–30% шалгалттай, дэмжлэгийн төрөл)
- Drive/Docs хавсралтын линкийн шалгалт + хадгалагдах хавтасны замын урьдчилсан харагдац
- Илгээмэгц и-мэйл баталгаажуулалтын урьдчилсан харагдац (To / Cc / Гарчиг / Агуулга)
- Амьд «Хүсэлтийн товч» самбар: гүйцэтгэлийн %, шаардлагын шалгалт, хариу өгөх хугацаа
- «Миний хүсэлтүүд» + аудитад зориулсан «Бүртгэлийн сан» (шүүлттэй хүснэгт)
- 4 алхамт танилцуулга, гэрэлтэй/харанхуй горим

## Прототип ба production-ы ялгаа

Прототипод и-мэйл илгээлт, Drive хадгалалт, нэвтрэлтийг **дуурайлгаж** харуулна (өгөгдөл хөтөч дээр хадгалагдана). Production дээр:
- Google Workspace OAuth (@netcapital.mn домэйн хязгаарлалттай)
- Gmail API / Apps Script-ээр жинхэнэ и-мэйл бүртгэл
- Drive API-аар хавсралтыг ангилсан хавтаст автоматаар хуулах
- Серверийн өгөгдлийн сан + CSV/Excel экспорт (аудит)

## Турших

`index.html`-ийг хөтчөөр нээхэд л хангалттай. User case тестүүд: `test2.js` (Playwright, 12 тохиолдол).

# IPPDD WorkOS — ажиллаж буй прототип (artifact)

Хэрэглэгчид шууд ашиглуулж буй нэг файлын прототип. Албан ёсны систем (энэ репогийн
Next.js + Supabase апп) идэвхжтэл түр хэрэглэгдэнэ; «Прототип» гэж үнэнчээр шошготой.

- **Нийтлэгдсэн хаяг:** https://claude.ai/code/artifact/b338c8df-30be-49b5-8fb6-b9a04e78e2ff
- **Угсрах:** `python3 build_app.py` → `workos-demo.html` (эх хэсгүүд + пилот өгөгдөл `demo_data.json`)
- **Capabilities:** `db` (багийн хамтын сан) + `sample` (AI туслах) + `mcp` (Google Drive `read_file_content` + `search_files` — G8 EOM шалгалт, «Баримт шалгах») — дахин нийтлэхдээ
  `capabilities`-ийг орхивол хэвээр үлдэнэ.
- **Пилот өгөгдөл:** `demo_data.json` — IPPDD_OKR_Q3_2026-08-01_v1.0 workbook-оос экспортолсон
  (3 зорилт, 10 KR, 5 ажил). Юу ч зохиогоогүй.

## Хэсгүүд

| Файл | Агуулга |
| --- | --- |
| `app_head.html` | Theme токен (3 блок), нэвтрэлт/side nav/карт/chain/check-in CSS, print CSS |
| `app_engine.js` | Gate Engine порт: PROFILES, TRANSITIONS, `evaluateGate` |
| `app_main.js` | Төлөв, session (20 мин), theme, хамтын сан (db), бүх үйлдэл `A.*` |
| `logo_sprite.html` | Байгууллагын логоны inline SVG symbol (`#nfgMark`) |
| `app_render.js` | Бүх дэлгэц: нүүр, OKR, хяналт/батлал, 7 алхамт chain, Check-in, тайлан, админ |
| `app_wire.js` | Event delegation, AI туслах (`sample`), Check-in AI дүгнэлт |

## Хувилбарууд

- v9.0 — **хүн тус бүрийн OKR + доош хуваарилалт (cascade) + хянагчгүй урсгал**:
  1) Ажилтанд тусад нь томилогдсон хянагч байхгүй болов — агуулгын хяналт ба батлал нь
     газрын захирлын НЭГ шийдвэр (G4 «Захирлын хянаж батлах»); зөвхөн AI_AGENT ажилд
     өөр нэгжийн (IT) хараат хяналт үлдэв. «Илгээх» товч шууд захирлын дараалалд оруулна
     (өмнө SUBMITTED дээр гацдаг байсан алдааг зассан).
  2) KR бүр `owner`, `dept`, `parent` талбартай болж, «Миний OKR» нь нэвтэрсэн хүний
     ӨӨРИЙНХ нь OKR-ийг харуулна. Google Sheet линкээр OKR импортлох (нээгчийн өөрийн
     Google эрхээр уншиж AI-аар задална, урьдчилан харуулаад баталгаажуулна).
  3) Захирал/CIO-гийн OKR хуудсанд «Доош хуваарилалт (cascade)» — KR бүр хэнд
     хуваарилагдсан, тэр хүн хэрхэн хийж байгаа (гүйцэтгэл, ажил, хоцролт, ажил бүрийн
     үнэлгээ), «Ажилтан тус бүрээр» нэгтгэл; шатлалыг select-ээр холбоно.
  4) «Хяналт» + «Батлал» → нэг **«Миний дараалал»** (хяналт, хянаж батлах, CIO зөвшөөрөлт,
     sign-off, хүлээн авалт бүгд нэг дор, badge тоологчтой).
  5) Өгөгдөл **нөөшлөх/сэргээх** (JSON clipboard, Админ хэсэгт); аудитын лог 60 → 200.

- v8.2 — системийн нэр **«Нэткапитал WorkOS»** болов (нэвтрэх гарчиг, зүүн цэс, `<title>`,
  AI туслах, гэрчилгээ, AI-ийн системийн prompt). Нэвтрэх дэлгэцийн дэд мөр нь олон газарт

  (IPPDD-2026Q3-…) болон газрын нэрс бодит дата тул хөндөөгүй.

- v8.1 — **QA/production аудитын засварууд** (бодит хэрэглээний тестээр илрүүлсэн):
  1) `safeUrl()` — `javascript:`/`data:` линк href-д хэзээ ч орохгүй (хамтын сан итгэмжлэгдээгүй
     тул render үед дахин шүүнэ; буруу линк «линк буруу» тэмдэгтэй текстээр харагдана);
  2) `grabFormState`/`restoreFormState` — хамтын сангийн snapshot ирэхэд бичиж байсан оруулга,
     нээсэн хэсэг, focus, caret устахаа болив (олон хүн зэрэг ажиллахад оруулга алдагдахгүй);
  3) мобайл доод цэс хэвтээ гүйлгэгддэг болов (9 таб 390px дээр бүгд хүрэх боломжтой);
  4) `mergeWork()` — бичихийн өмнө уншиж id-гаар нэгтгэдэг болов (өөр хүний зэрэг нэмсэн
     нотолгоо/батлал дарагдахгүй; транзакц биш — зөрчлийг багасгах арга);
  5) `db` rules: `write: "admin"` — линкийг «зөвхөн харах» эрхээр хуваалцвал гадны хүн
     бичиж чадахгүй, бичих эрхийн алдааг үнэнч мессежээр харуулна;
  6) нэвтрэлт, зөвшөөрлийн бүртгэлд «хувь хүнээр баталгаажаагүй» гэсэн ил тэмдэглэл.

- v8.0 — **газрын баримтын хүрээтэй тулгалт**. «Баримт шалгах» хэсэгт хүрээний хавтас
  (бодлого/стандарт/журам/бүртгэл) ачаалагдаж хамтын санд `meta/framework`-т хадгалагдана;
  нэрээс төрөл/хувилбар/огноог `fwMeta()` задална (node тесттэй). Шалгалт бүр EOM-ийн
  хэлбэрийн шалгуур ДЭЭР НЭМЖ хүрээтэй тулгана (дурдсан холбоос бүртгэлд байгаа эсэх,
  хувилбарын зөрүү, давхардал — `crit=FRAMEWORK`). Ажлын хуудсанд шинэ «Ажил ↔ баримтын
  тулгалт» карт: хавсаргасан эцсийн баримтуудын агуулгыг уншиж шаардлага тус бүрийг
  MET/PARTIAL/MISSING-ээр, DoD-ийг MET/PARTIAL/NOT_MET-ээр дүгнэж, хүрээтэй зөрчил + хийх
  ажлын жагсаалт гаргана; Check-in тайланд хураангуй нь тусна.
